# NHL goalie-input correction — November 24, 2026

The current team model, bet gates, 400,000-game simulation protocol, skater model and fresh command workflow remain in place. This change corrects the goalie-quality input rather than inflating probabilities after losses.

## Correct individual expected goals

Previously a team's score/venue-adjusted expected goals against were distributed among its goalies in proportion to shots faced. Empty-net chances and uneven shot difficulty between starters and relief goalies make that an imperfect individual measure. v4.2 uses MoneyPuck goalie-game xGoals directly, but only when goalie identity, goals conceded and shots against match the NHL box score. Source: https://moneypuck.com/data.htm (listed season goalie ZIPs). Credit: MoneyPuck.com.

The compact cache covers 2021–22 onward. At the input snapshot, 14,559 goalie-game records matched; 167 retained the old team-shot-share proxy. Missing, invalid or conflicting records do not invent individual quality. A validated older cache survives failed downloads; current-season data refresh every six hours. Forecasts still refresh official starter/roster/news feeds on each command. Complete past dates only enter model state. Data files may contain later games, but only the current ingested game's ID can supply its observation.

The central regression is refitted on these corrected prior features. A separate fit using the old proxy supplies additional scoring and goalie sensitivity distributions; a recommendation must retain the existing >50% and positive fee/quote-stressed EV requirements under those as well. The model's version records the input change. Stored model metadata reports matched/fallback counts. No historical Discord card is regenerated for grading.

## Chronological evidence and limits

Using the same monthly walk-forward refits and production-simulator grid as earlier research, goalie-specific data changed winner/exact-score log loss on 1,312 games in 2025–26 by −0.000053/−0.000246 and on 372 games in 2026–27 through November 21 by −0.000637/−0.001084. Earlier 2023–25 periods were slightly worse. The late-period gains are small and uncertainty intervals generally include zero. This is a verified input correction with mixed exploratory performance evidence, not a demonstrated win-rate improvement or an ROI backtest.

Actual historical starting goalies are optimistic versus morning information. November 22–23 are excluded from this research, and no outcome from a current game enters its own features. Production feature rows reproduce the independently implemented research calculation to 1e-10. The corrected NHL GA/SA matching prevents directly importing a provider's mismatched goalie appearance.

## Rejected special-teams candidates

We also added separately shrunk power-play attack, penalty-kill defense/opportunity and even-strength features from MoneyPuck's listed team-game data. Six configurations (20/40/80 pseudo-games, with/without extra even-strength features) failed to beat the baseline exact-score log loss on the 2023–25 selection period. Some later metrics improved slightly, but none was promoted. Screen JSONs preserve the unfavorable evidence.

Reproduce goalie-quality-nov24.py with the six official season goalie ZIPs under /tmp/nhl-goalies-YEAR-nov24.zip and uncertainty-grid-nov23.js's generated grid in this research folder. The special-team scripts additionally expect the listed all_teams.csv at /tmp/nhl-all-teams-nov24.csv. Large downloaded archives and generated grids/rate tables are excluded from this change; only the minimal operational goalie cache and source hashes are stored.

Validation covers parser/identity conflicts, invalid and duplicate archives, cache fallback, strict prior-day ingestion, exact goalie versus team-proxy assignment, legacy model sensitivity, existing availability/bet/depth/publication rules, routing and daily grading.
