# NHL lineup context — November 9, 2026

## Problem

The model retrieved live injuries but had only team-level skater strength. It blocked bets when an injury report's update date was later than the latest fitted game. That date is not the onset of an absence. Official player logs show several screenshot players last appeared well before the November 8 training cutoff. A flat new-player penalty would double count some of their absence and still miss roster returns/replacements.

## Change

Build a market-free player/participation state from official NHL regular-season game logs. Player quality is goals plus half an assist per game above the position average, shrunk with 20 games of position-average prior. It is a production proxy, not a complete causal player rating. Player prior exposure carries 70% between seasons. Team participation has the existing 25-game half-life and 30% season carry. Compare the expected lineup's summed player quality with that team's weighted historical lineup mixture, using current prior-only player estimates for both. Thus an already-absent player is not treated as a newly lost full-time starter simply because an injury report was edited.

Expected lineups use the current official NHL roster, exclude explicitly unavailable skaters, and select 12 forwards/6 defensemen by prior average ice time. Replacements are actual roster players with NHL history. These are expected, not confirmed game-day actives: healthy scratches, unusual 11F/7D formations, minutes changes, line chemistry and power-play roles are not comprehensively covered. Ambiguous players, absent performance data, inadequate roster depth, source failure, out-of-range context or future-dated history still withhold recommendations.

An opposing/own lineup-production feature maps to a small multiplicative scoring adjustment via a strongly regularized Poisson residual model. Coefficients were fitted before the 2026–27 season. Player statistics and team participation refresh on each command from newly completed prior-day games; current injuries and rosters refresh independently each command. No market prices are read by the skater layer. Injured players with no prior participation on this team contribute zero to its historical lineup mixture. A player with no recorded NHL history who is also absent from the official roster is disclosed as having no existing modeled contribution to remove; an expected lineup player without performance history blocks the adjustment.

The original unadjusted team forecast is retained as a required betting sensitivity scenario, together with its scoring-scale stresses. Questionable skaters get an additional OUT-lineup stress. A bet must remain above 50% with positive fee-inclusive EV in all these scenarios, plus the displayed-score, liquidity and pregame checks. This new layer cannot create a qualifying edge that fails the original team forecast. It does remove the blanket date-based injury veto when the lineup can actually be evaluated. Frozen/started forecasts are not rewritten.

## Research evidence and limitations

`fetch-skater-history.py` reproduces official NHL game-by-game inputs from September 2024 through November 8, 2026; `skater-screen.py` shares the production feature code. The source includes 104,605 skater game rows over 2,906 games. The stored current context contains 1,106 players. Only earlier dates' player performance enters each forecast's features; the historical participant identities are known, which is optimistic versus live expected lineups.

Baseline team GLMs are refitted on dates strictly before each weekly research block. First fit uses 712 games in the latter part of 2024–25. Four fixed ridge penalties (1,10,100,1000) were screened on the first 399 games in 2025–26. All four were worse than the unchanged model there; 1000 was least harmful. No new penalties were selected from later outcomes. On 913 later 2025–26 games, the small layer improved mean Poisson score by approximately .000472 per team, with a date-cluster bootstrap 95% interval [.000036,.000886]. Coefficients fitted through April 16, 2026, evaluated on all 282 2026–27 games through November 8 improved mean Poisson score by .000764, but its interval [-.000303,.001762] crosses zero; team-score MAE slightly worsened (1.368194 → 1.368323).

This does **not** establish a reliable accuracy or betting-return gain, and the historical periods were available in previous research. Accordingly the effect is small and used conservatively with the unchanged baseline as a mandatory stress. No star-player-sized arbitrary goal deductions are introduced, and no 80% win rate is claimed. Prospective delivered-bet/model learning evaluates the distinct `v4-independent-skater-v1` model version. No automatic coefficient promotion.

Reproduce:

```sh
python research/fetch-skater-history.py --out /tmp/nhl-skater-research
python research/skater-screen.py --skaters /tmp/nhl-skater-research/skaters.json.gz --out /tmp/skater-screen.json
```

The skater input SHA-256 is recorded in `skater-screen.json`; later official statistical corrections can change a re-download. Live testing on the three screenshot matchups successfully modeled availability and cleared their generic "recent skater absences not individually modeled" reason. This does not mean each game has a qualifying bet. No live Discord messages were sent.
